# GharMilo

A simple static website for the GharMilo project.

## Files

- `index.html` — main page
- `netlify.toml` — Netlify deployment configuration

## Usage

Open `index.html` in your browser to view the website.

## Deployment

This project is configured for Netlify. Push to GitHub and connect the repo to Netlify to deploy automatically.
